**The ClickHouse sink names the reason a reserved setting is refused** (`spate-clickhouse`)

A reserved setting in the sink's `settings` map fails at load with the message every connector uses for an owned key, and the reason the sink owns it, such as `sink.clickhouse: settings."insert_deduplicate" cannot be overridden: forced to `1`, so the server deduplicates a retried batch by its token`. In previous versions it read ``sink.clickhouse: setting `insert_deduplicate` is managed by the sink and cannot be overridden``, with no reason. Only the exact names are refused, because ClickHouse has no alias of them and fails a request that spells one otherwise.
