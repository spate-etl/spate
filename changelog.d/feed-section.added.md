**A `feed:` section selects the work feed** (`spate-core`, `spate-s3`, `spate-test`)

A pipeline file can name the feed its source reads with a top-level `feed:` section: one backend key, plus `units_held`, `attempt_cap`, `location`, a job location for a source that reads one, and `settling_window`, the settling window of a job that names one; the in-process feed refuses the last two, and `settling_window` is refused below 20 seconds and above 24 hours. The section is `spate_core::config::FeedSection`, and the runtime hands it to the source through `Source::configure_feed`, whose default refuses the section. The runtime builds the in-process feed itself for `feed: { memory: {} }`, through `MemoryFeed::from_section`. Any other backend is built in code and passed to `Pipeline::feed`, and the runtime refuses a feed whose `Feed::backend` key differs from the section's. `MemoryFeed::with_attempt_cap` sets the delivery on which the in-process feed dead-letters a failed unit. The S3 source reads work units from the feed the section names, with `units_held` bounding its read parallelism (default 96). A unit the lister publishes names one object or one byte range of one object, and a notification message is one unit with one part per non-empty created object; a whole-object unit whose descriptor carries an ETag, over an object that qualifies for byte ranges, is read in ranges, each range in progress taking one of `units_held`. On a durable feed it lists nothing: it reads the units and storage notifications published to the feed, and publishes only the notification unit it re-enqueues after an overwrite, capping those re-enqueues at `attempt_cap`. On the in-process feed it lists its own prefix into the feed, and code can publish more units to a `MemoryFeed` it keeps a handle to and passes to `Pipeline::feed`, in which case the run ends only at a shutdown. Units from another process need a durable backend. Without a `feed:` section it plans splits as before, and a file that sets both `feed:` and `coordination:` fails to load.
