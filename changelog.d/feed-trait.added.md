**A feed trait for queue-fed sources** (`spate-core`, `spate-test`)

`spate_core::feed::Feed` is the contract a source uses to read work units from a queue. A source receives units, renews the ones it holds, and acknowledges or fails each one. A publisher adds units and reads a `Confirmation` that reports when the feed has stored each one. `spate_core::feed::memory::MemoryFeed` is an in-process feed for one instance. It keeps nothing across a restart and moves a unit that fails on its tenth delivery to an in-memory dead-letter list. A backend that can count what it holds answers `Feed::read_depth`, and `spate_core::feed::EndCheck` decides from those counts when a bounded job has read all of its work. `Source::configure_feed` learns from a `FeedOrigin` whether the runtime built the feed or code passed it in. `spate_test::scripted_feed` lets a test script redelivery, duplicate delivery, dead letters, publish outcomes, depth reads, and refusals of the next `receive`, `renew`, `acknowledge` or `fail` with a given `FeedErrorKind`.
