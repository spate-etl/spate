**A Kafka source or feed fetches each partition once when it takes an assignment** (`spate-kafka`)

The Kafka source now pauses each partition at the consumer before it accepts the assignment, so no fetch completes before the source sets up the partition's lane. The Kafka feed does the same for each partition it seeks to its committed offset, and for every partition when it is stopping or holds as many units as it buffers. In previous versions a fetch that completed just after the assignment was discarded and the same records were fetched again, so `spate_kafka_source_rx_messages_total` or `spate_kafka_feed_rx_messages_total` could count a partition's first batch twice. Each record still reached the pipeline once.
