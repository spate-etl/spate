**The S3 source reads storage notifications from its feed** (`spate-s3`)

On the feed path, the S3 source reads storage notifications as well as the units a lister publishes. It reads an S3 `Records[]` message, the same records inside the envelope RustFS sends, and the S3 test event, which it acknowledges with nothing to read. Each `ObjectCreated:*` record becomes one part of the message's unit. Its key is decoded as `application/x-www-form-urlencoded`, and its ETag is sent quoted in `If-Match`. Records that create nothing, and created objects of size 0, are dropped. The message is failed back to the feed, which dead-letters it at its cap, when any created record names another bucket, a key outside the source's prefix, no size, or a key that does not decode or that `object_store` cannot read under its own name. The message is acknowledged once, after every part has been read. An object announced by both a listing and a notification is read twice.
