**The S3 source trusts a private CA through `tls.root_ca`** (`spate-s3`)

`source: { s3: { tls: { root_ca: <path> } } }` names a PEM bundle whose certificates the source trusts in addition to the system trust store, for its store and credential calls. A file that cannot be read, holds no certificate or holds one that does not parse fails opening the source at `source.s3.tls.root_ca`. The key is refused at load when `url` is not an S3 store, or when `store` sets an endpoint that is not `https://`. With `disable_system_certificates: "true"` under `store`, the source trusts the `tls.root_ca` certificates alone. A certificate from an unknown issuer now fails with a hint to add the issuing CA to the system trust store, or to `tls.root_ca` when the source accepts that key.
