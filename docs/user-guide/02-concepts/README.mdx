# Concepts

The mental model behind Spate. These pages explain the contracts the
framework holds, and the ones it expects you to hold, with the reasoning
behind each. The reasoning behind each decision lives in the
[decision records](../../adr/README.mdx);
these pages are the working subset a pipeline author needs.

## [1. Architecture](01-architecture.mdx)

The anatomy of a running pipeline process: pipeline threads (poll →
deserialize → operator chain → route → encode), the single shared tokio I/O
runtime (sink workers, admin server, async fetchers), and the control plane.
Why one process runs exactly one pipeline.

## [2. Delivery guarantees](02-delivery-guarantees.mdx)

How at-least-once works: refcounted acknowledgments per source batch, the
contiguity tracker, and watermarks that commit only after durable sink acks,
across assignment changes and shutdown. Also the limits: what a dedup token
does and does not cover, and how to design destinations for replay.

## [3. Backpressure](03-backpressure.mdx)

Flow control without ever blocking the source: `try_send`, pause, keep
polling. The in-flight byte budget, its watermarks, and the sizing rule that
keeps a saturated pipeline out of pause duty-cycling.

## [4. Error handling](04-error-handling.mdx)

The error taxonomy (retryable, record-level, fatal), the two record-level
policies (Skip and Fail, with no dead-letter queue), and the metrics
that make every drop and every error visible.

## [5. Sink sharding](05-sink-sharding.mdx)

How the terminal stage fans writes across shards: what a shard is, the two
router tiers (meta-only `KeyHashRouter` and record-aware `RecordRouter`), why
one saturated shard pauses the whole pipeline, and the limit that hot shards
are your data's shape, not the router's choice.

## [9. Work feed](09-work-feed.mdx)

How a source reads work units from a queue: the ack rule that ties a unit's
acknowledgment to the sink's, redelivery and duplicates under new receipts,
dead-lettering at the delivery cap, and how the control plane waits on the
feed without blocking.
