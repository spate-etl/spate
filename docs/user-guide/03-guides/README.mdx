# Guides

Task-oriented how-tos. Each guide gets you to one concrete outcome; none of
them re-explains the architecture — for that, start with
[Concepts](../02-concepts/README.mdx) or [docs/DESIGN.md](../../DESIGN.md).

| Guide | Outcome |
|---|---|
| [Assembling a pipeline](assembling-a-pipeline.mdx) | Build and run a pipeline with the `Pipeline` builder — the primary assembly path. Read this one first. |
| [Configuring pipelines](configuring-pipelines.mdx) | Write a pipeline YAML: typed framework sections, environment interpolation, opaque connector sections. |
| [Testing pipelines](testing-pipelines.mdx) | Test a whole assembly deterministically with `etl-test`'s in-memory source and capturing sink. |
| [Schema validation](schema-validation.mdx) | Fail fast when your row struct, `columns` list, and the live ClickHouse table disagree. |
| [Graceful shutdown](graceful-shutdown.mdx) | Drain cleanly on SIGTERM, size `drain_timeout` against Kubernetes, and interpret exit codes. |
| [Securing connections](securing-connections.mdx) | Connect to a TLS/mTLS/SASL-secured Kafka cluster with the opt-in `kafka-tls` feature; ClickHouse over HTTPS. |
| [Manual assembly](manual-assembly.mdx) | Desugar every builder step into the public primitives it composes — the escape hatch. |
