## Configuration

The `SECTION: { NAME: ... }` section deserializes into `NameConfig`
(`crates/spate-NAME/src/config.rs`); unknown fields are rejected with the
offending key.

```yaml
SECTION:
  NAME:
    key: value
```

| Key | Type | Default | Description |
|---|---|---|---|
| `key` | string | `required` | What it does. |
| `other` | duration | `5s` | Defaults are one of exactly three forms: `required`, a backticked literal, or `none`. Never prose. |
