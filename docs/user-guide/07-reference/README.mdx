# Reference

Where to look things up. This guide teaches concepts and contracts; the
sources of truth it defers to are listed here.

## In this section

- [Configuration](configuration.mdx) — the full YAML schema: every key,
  type, and default in the framework sections, plus pointers to each
  connector's own section.
- [Glossary](glossary.mdx) — precise definitions of the terms used
  throughout the guide (lane, epoch, watermark, sealed batch, ...).

## API reference (docs.rs)

Signatures, trait contracts, and per-item docs live in the rustdoc:

| Crate | Role |
|---|---|
| [spate](https://docs.rs/spate) | The facade — the only crate applications depend on. Feature-forwards the connectors (`kafka`, `clickhouse`, `s3`, `avro`, `json`, `coordination`, `full`). |
| [spate-core](https://docs.rs/spate-core) | The engine: record/ack types, source/sink traits, operator chain, checkpointer, backpressure, pipeline builder and runtime, config, metrics, admin server. |
| [spate-kafka](https://docs.rs/spate-kafka) | Kafka source (single consumer, split partition queues) and producer sink. |
| [spate-clickhouse](https://docs.rs/spate-clickhouse) | ClickHouse `ShardWriter` with Native and RowBinary encoders. |
| [spate-s3](https://docs.rs/spate-s3) | Coordinated object-storage backfill source: planned splits, fenced per-split progress. |
| [spate-avro](https://docs.rs/spate-avro) | Avro deserializer: Confluent wire format, schema-registry client. |
| [spate-json](https://docs.rs/spate-json) | JSON deserializer: single, NDJSON and array framings, optional SIMD backend. |
| [spate-coordination](https://docs.rs/spate-coordination) | Distributed work assignment: leader-elected planner, leases and fenced commits over a pluggable store. |
| [spate-test](https://docs.rs/spate-test) | In-memory source/sink mocks with scripting handles, for testing pipelines. |

Applications should import through `spate` (which re-exports the connector
crates behind features); the per-crate docs matter mostly to connector
authors — see [Extending](../06-extending/README.mdx).
