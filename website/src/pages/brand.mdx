# Brand

The mark is a confluence: three sources feed one core and leave through one sink,
the shape of a pipeline whose partitions fan into a single monomorphized loop.
Every asset on this page is generated from one source in the repository, so a
file here is never hand-edited.

## The lockup

The wordmark is IBM Plex Sans SemiBold, tracked to −0.022 em, with the mark's
ink centered on the x-height. Use the lockup where the name has to be read; use
the mark alone where the name is already beside it.

## Color

One accent, two grounds. The mark's colors and the accent that carries link
text differ on the light ground, because a graphic reads at 3:1 and text has to
clear 4.5:1. Every pair below is checked by `make check-brand`.

## Type

IBM Plex Sans for text, IBM Plex Mono for code and figures, both under the SIL
Open Font License. Headings are SemiBold with tight tracking; body text is
Regular at 16 px on a 1.6 line height.

## Rules

- Keep clear space around the mark of at least the core square's width.
- Do not recolor the mark. On a colored ground, use the lockup for the
  ground's tone or the avatar, which carries its own ground.
- Do not rotate, outline, add effects, or set the wordmark in another face.
- The smallest the mark renders legibly is 16 px; below that, use the favicon.
- Spate is written with a capital S in prose and in lowercase in the wordmark.
